# Repository 9: Debugging & Bisect 🔴

**Master Git debugging tools and binary search for bugs**

## 🎯 Learning Objectives

- Use git blame to track code changes
- Master git bisect for finding bugs
- Automate bisect with test scripts
- Debug with git log search
- Use git grep for code search

## 📊 Difficulty: 🔴 Advanced

**Prerequisites:**
- Understanding of Git history and commit SHAs
- Ability to read and interpret git log output
- Familiarity with searching through commit history
- Basic scripting knowledge (for automated bisect)
- Understanding of what makes a "good" vs "bad" commit

**Where to learn:** [Repository 01: Foundations](../git-mastery-01-foundations) covers Git basics

**Estimated Time:** 5-6 hours

## 🚀 Getting Started

Run the setup script:

```bash
chmod +x build-history.sh
./build-history.sh
```

**Need to start over?** Just run `./build-history.sh` again and type `y` to reset!

Then start with [EXERCISES.md](./EXERCISES.md)!
